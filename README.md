# 하루 한 편 AI 논문

평일마다 주요 AI 논문 한 편을 정리해 올리는 기술 블로그입니다.

- 블로그 주소: <https://lakhepriatum.github.io>
- 글 위치: `_posts/`
- 글 템플릿: `_templates/post-template.md`
- 커리큘럼: `_data/curriculum.yml` (블로그의 "커리큘럼" 페이지가 이 파일을 읽어 표시합니다)
- 작성 규칙: `CLAUDE.md` (논문 선정 기준, 글 형식, 검증, 게시 방식)

GitHub Pages가 Jekyll(minima 테마)로 자동 빌드합니다. `main`에 병합되면 1~2분 안에 블로그에 반영됩니다.

## 운영 방식

1. 예약 작업이 평일마다 논문 한 편을 골라 글을 쓰고 PR을 엽니다. 월~목요일은 커리큘럼의 다음 논문, 금요일은 최근 한 달 안에 나온 논문입니다.
2. PR에서 글을 검토하고, 고칠 부분이 있으면 댓글을 남기거나 직접 수정합니다.
3. PR을 병합하면 글이 게시됩니다.

다룰 논문과 순서를 바꾸려면 `_data/curriculum.yml`을, 선정 규칙이나 글 형식을 바꾸려면 `CLAUDE.md`를 수정하면 됩니다.
