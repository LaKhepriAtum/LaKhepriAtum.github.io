## 한 줄 요약

ViT는 이미지를 16×16 픽셀 조각(패치)으로 잘라 한 줄로 늘어놓고, 각 조각을 단어 토큰처럼 BERT식 Transformer 인코더에 넣어 분류합니다. 합성곱이 주는 "가까운 픽셀끼리 묶어 본다"는 가정 없이도, 3억 장 규모로 사전학습하면 당시 최고 CNN보다 적은 연산으로 더 높은 정확도를 냈습니다. 이후 CLIP, SAM, LLaVA 같은 모델의 이미지 인코더가 이 구조를 이어받았습니다.

## 배경: 어떤 문제를 풀려는가

이 글은 커리큘럼 이미지 트랙의 첫 번째 글입니다. [Transformer](/2026/11/23/transformer-attention-is-all-you-need/), [ResNet](/2026/11/23/resnet-deep-residual-learning/), [BERT](/2026/11/24/bert-bidirectional-pretraining/) 글을 먼저 읽어 두면 좋습니다. ViT의 몸체는 BERT 인코더 그대로이고, 비교 대상은 ResNet입니다.

2020년의 NLP는 Transformer로 통일됐지만 이미지 인식은 여전히 CNN이 주류였습니다. 어텐션을 이미지에 쓰려는 시도는 대부분 합성곱과 섞거나 어텐션 범위를 주변 픽셀로 좁힌 특수 구조여서, 가속기에서 효율적으로 돌리기 어려웠습니다(1~2절).

픽셀 하나를 토큰 하나로 쓰지 못하는 이유는 비용입니다. 224×224 이미지는 50,176픽셀이라 어텐션 행렬 칸이 약 25억 개입니다. 16×16 패치로 자르면 토큰 196개, 칸 38,416개로 65,536배(=256²) 줄어듭니다.

CNN은 "가까운 픽셀이 중요하다", "같은 무늬는 어디 있든 같다"는 가정을 구조에 박아 둡니다. 신입 사원에게 업무 요령을 미리 알려 주는 셈이라 데이터가 적을 때 빨리 배웁니다. ViT는 이 요령 없이 데이터에서 직접 배워야 합니다. 이 논문의 발견은 데이터가 충분히 많으면 요령 없는 쪽이 더 멀리 간다는 것입니다.

## 핵심 아이디어

### 이미지를 패치 시퀀스로 바꾸기

H×W×C 이미지를 P×P 패치로 자르면 패치 수는 `N = HW / P²`, 패치 하나는 길이 `P²·C`인 벡터입니다(3.1절). 224×224 RGB를 16×16으로 자르면 196개 패치, 패치당 768개 값입니다. 입력 시퀀스는 다음과 같습니다.

`z_0 = [x_class; x_p^1 E; x_p^2 E; …; x_p^N E] + E_pos`

- `x_p^i E`: i번째 패치를 D차원으로 투영한 패치 임베딩. `E`의 크기는 `(P²·C) × D`입니다.
- `x_class`: BERT의 `[CLS]`처럼 맨 앞에 붙이는 학습 가능한 벡터. 마지막 층에서 이 자리의 출력이 이미지 표현이 됩니다.
- `E_pos`: 크기 `(N+1) × D`의 학습 가능한 1차원 위치 임베딩.

이후는 레이어 정규화를 먼저 하는 표준 인코더 블록입니다.

`z'_l = MSA(LN(z_{l-1})) + z_{l-1}`, `z_l = MLP(LN(z'_l)) + z'_l`

MSA는 멀티헤드 셀프 어텐션, MLP는 GELU를 쓴 2층 신경망입니다. 마지막 층의 class 토큰 출력에 LN을 거쳐 분류기를 붙입니다. 분류기는 사전학습 때 은닉층 하나짜리 MLP, 미세조정 때 선형층 하나입니다.

### 가상의 숫자로 따라가 보기

4×4 흑백 이미지와 2×2 패치로 따라가 보겠습니다(가상의 숫자). 픽셀 값이 왼쪽 위부터 1, 2, …, 16이면 패치는 p1=[1, 2, 5, 6], p2=[3, 4, 7, 8], p3=[9, 10, 13, 14], p4=[11, 12, 15, 16]입니다.

D=2로 투영하는 `E`의 첫 열을 [0.25, 0.25, 0.25, 0.25](평균 밝기), 둘째 열을 [-0.5, 0.5, -0.5, 0.5](오른쪽 열 − 왼쪽 열)로 두면, p1은 [3.5, 1.0], p2는 [5.5, 1.0], p3는 [11.5, 1.0], p4는 [13.5, 1.0]이 됩니다. 실제 ViT가 학습한 `E`의 주성분도 패치 안 미세 구조를 표현하는 기저 함수처럼 생겼습니다(4.5절, 그림 7).

셀프 어텐션은 순서를 모르므로 `E_pos`가 없으면 네 패치를 섞어 넣어도 class 토큰의 출력이 같습니다. 모델에게 이미지는 패치들의 주머니가 됩니다.

### 해상도를 바꿔 미세조정하기

미세조정은 사전학습보다 높은 해상도로 하는 것이 유리합니다(3.2절). 패치 크기는 그대로이므로 384 해상도에서는 패치가 14×14=196개에서 24×24=576개로 늘어납니다. 학습된 위치 임베딩은 196개뿐이라, 이를 14×14 격자로 되돌려 2차원 보간으로 24×24로 늘립니다. 사람이 이미지의 2차원 구조를 직접 넣는 곳은 이 보간과 패치 자르기 두 곳뿐입니다.

### 의사 코드

```python
def vit_forward(img, P, E, cls, pos, blocks, head):
    B, H, W, C = img.shape
    x = img.reshape(B, H // P, P, W // P, P, C)
    x = x.transpose(0, 1, 3, 2, 4, 5)           # 패치 격자 축을 앞으로
    x = x.reshape(B, (H // P) * (W // P), P * P * C)  # (B, N, P²C)
    z = x @ E                                    # (B, N, D)
    z = concat([cls.repeat(B), z], axis=1) + pos # (B, N+1, D)
    for blk in blocks:                           # pre-LN 블록
        z = z + blk.msa(layer_norm(z))
        z = z + blk.mlp(layer_norm(z))
    return head(layer_norm(z[:, 0]))             # class 토큰 자리만 사용
```

`transpose`를 빼먹는 실수가 흔합니다. 그대로 `reshape`하면 정사각형이 아니라 가로로 긴 띠가 패치가 됩니다. 실무 구현은 커널과 보폭이 모두 P인 합성곱 한 층으로 이 세 줄을 대신하며, 두 방식은 수학적으로 같습니다.

## 실험 결과

### 설정

모델은 BERT의 Base, Large에 Huge를 더한 세 가지입니다(표 1). ViT-L/16은 16×16 패치를 쓰는 Large입니다.

| 모델 | 층 | 은닉 D | 헤드 | 파라미터 |
|---|---|---|---|---|
| ViT-Base | 12 | 768 | 12 | 86M |
| ViT-Large | 24 | 1024 | 16 | 307M |
| ViT-Huge | 32 | 1280 | 16 | 632M |

사전학습 데이터는 ImageNet(130만 장), ImageNet-21k(1,400만 장), 구글 내부 JFT-300M(3억 300만 장)입니다(4.1절). 사전학습은 Adam과 배치 4096, 미세조정은 모멘텀 SGD와 배치 512입니다. 비교 대상은 큰 ResNet을 전이 학습한 BiT-L과 준지도 EfficientNet인 Noisy Student입니다.

### 주요 결과

표 2의 일부입니다(미세조정 3회 평균).

| 데이터셋 | ViT-H/14 (JFT) | ViT-L/16 (JFT) | ViT-L/16 (I21k) | BiT-L | Noisy Student |
|---|---|---|---|---|---|
| ImageNet | 88.55 | 87.76 | 85.30 | 87.54 | 88.4 |
| CIFAR-100 | 94.55 | 93.90 | 93.25 | 93.51 | − |
| VTAB (19개 과제) | 77.63 | 76.28 | 72.72 | 76.29 | − |
| TPUv3 코어·일 | 2.5k | 0.68k | 0.23k | 9.9k | 12.3k |

- ViT-L/16(JFT)은 BiT-L과 VTAB에서 사실상 같고(76.28 대 76.29) 나머지 과제에서는 앞서면서, 사전학습 연산은 약 15분의 1입니다.
- ViT-H/14는 ImageNet에서 Noisy Student를 근소하게 넘었고, 연산은 약 5분의 1입니다.
- 공개 데이터인 ImageNet-21k로 학습한 ViT-L/16은 코어 8개짜리 TPUv3 한 대로 약 30일이면 학습됩니다(4.2절).

### 데이터가 적으면 진다

가장 중요한 실험은 사전학습 데이터 크기를 바꾼 4.3절입니다. ImageNet만으로 사전학습하면 정규화를 조정해도 ViT-Large가 ViT-Base보다 나쁘고 BiT ResNet이 ViT를 앞섭니다(그림 3). ImageNet-21k에서는 비슷해지고, JFT-300M에서야 큰 모델의 이점이 온전히 나옵니다.

JFT를 9M, 30M, 90M, 300M으로 잘라 본 실험(그림 4)도 같습니다. 비슷한 연산의 ViT-B/32와 ResNet50을 보면, 9M에서는 ViT가 훨씬 나쁘지만 90M 이상에서는 앞섭니다. 데이터가 적을 때는 CNN의 구조적 가정이 돕고, 많을 때는 직접 배우는 쪽이 낫다는 해석입니다.

### 그 밖의 분석

- **규모(4.4절, 그림 5)**: 같은 성능에 ViT는 ResNet보다 약 2~4배 적은 연산을 씁니다. ResNet 특징 위에 ViT를 얹은 하이브리드는 작은 모델에서만 조금 낫습니다. 시험 범위 안에서 ViT 성능은 포화되지 않았습니다.
- **위치 임베딩(부록 D.4, 표 8)**: ViT-B/16의 ImageNet 5-shot 선형 평가에서 위치 임베딩이 없으면 61.38%, 1차원 64.21%, 2차원 64.00%, 상대 위치 64.03%입니다. 있느냐가 중요하고 방식은 거의 상관없습니다.
- **어텐션 거리(4.5절, 그림 7)**: 낮은 층에서도 일부 헤드는 이미지 대부분을 봅니다. 층이 깊어질수록 보는 범위가 넓어집니다.
- **자기지도 학습(4.6절)**: BERT처럼 패치의 50%를 가리고 평균 색(512가지)을 맞히게 했더니(부록 B.1.2), ViT-B/16이 ImageNet 79.9%로 처음부터 학습한 경우보다 2%p 높았지만 지도 사전학습보다 4%p 낮았습니다.

## 한계

저자들이 밝힌 한계는 세 가지입니다. 최고 성능은 비공개 JFT에서 나왔고 ImageNet만으로는 ResNet에 집니다(4.3절). 분류만 다뤘고 검출과 분할은 과제로 남겼습니다(5절). 자기지도 학습은 지도 학습보다 4%p 낮았습니다(4.6절).

읽으면서 보인 주의점도 있습니다. 해상도를 키우면 토큰 수가 면적에 비례해 늘고 어텐션 비용은 그 제곱으로 늡니다. 모든 층이 같은 크기(1/16)의 특징만 만들어 작은 물체를 다루는 검출에 바로 쓰기 어렵습니다.

후속 연구가 이를 하나씩 다뤘습니다. DeiT(2020년 12월)는 학습 방법을 다듬어 외부 데이터 없이 ImageNet만으로 86M 파라미터 ViT를 83.1%까지 끌어올렸고, 컴퓨터 한 대로 3일이 안 걸렸습니다. "How to train your ViT?"(2021)는 증강과 정규화를 잘 조합하면 공개된 ImageNet-21k로도 JFT-300M 모델과 같거나 나은 성능을 낸다고 보였습니다. Swin Transformer(2021)는 어텐션을 지역 창 안으로 제한하고 창을 엇갈려 옮기는 계층 구조로 이미지 크기에 선형인 계산량을 얻었고, COCO test-dev 검출에서 58.7 box AP를 냈습니다. 자기지도 학습의 격차는 이 트랙 뒤에서 다룰 MAE와 DINOv2가 메웁니다.

## 실무에서 가져갈 점

- **지금 이미지 인코더의 기본형입니다.** LLaVA는 CLIP의 ViT-L/14 출력에 선형 투영 하나를 붙여 LLM 단어 임베딩 공간으로 보냅니다. SAM도 ViT-H 기반 이미지 인코더를 씁니다. 이미지를 토큰 시퀀스로 바꾸는 발상이 멀티모달 모델의 접점이 됐습니다.
- **패치 크기는 연산 손잡이입니다.** 224 해상도에서 패치를 32에서 16으로 줄이면 토큰이 49개에서 196개로 4배, 어텐션 행렬은 16배가 됩니다. 파라미터를 거의 늘리지 않고 성능과 비용이 함께 오릅니다(부록 D.2).
- **해상도를 바꿀 때는 위치 임베딩을 2차원으로 보간하세요.** class 토큰의 임베딩은 떼어 두고 나머지만 격자로 바꿔 보간한 뒤 다시 펼칩니다. 1차원 그대로 늘리면 행과 열 구조가 깨집니다.
- **데이터가 적으면 처음부터 학습하지 마세요.** 사전학습 체크포인트를 미세조정하는 것이 기본입니다. 원 논문 저장소는 AugReg 방식으로 다시 학습한 ImageNet-21k 체크포인트도 공개합니다.
