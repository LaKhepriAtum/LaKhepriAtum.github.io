## 한 줄 요약

RNN은 단어를 순서대로 하나씩 처리해야 해서 학습을 병렬화할 수 없었습니다. Transformer는 순환 구조와 합성곱을 모두 걷어 내고 어텐션만으로 문장 안의 모든 단어를 한 번에 연결합니다. 그 결과 훨씬 적은 학습 비용으로 당시 번역 최고 성능을 넘었습니다.

## 배경: 어떤 문제를 풀려는가

이 글은 커리큘럼 공통 기초 트랙의 다섯 번째이자 마지막 글입니다. [Bahdanau Attention](/2026/11/23/bahdanau-attention/)과 [ResNet](/2026/11/23/resnet-deep-residual-learning/) 글을 먼저 읽으면 구조의 절반은 이미 아는 내용입니다.

Bahdanau Attention 이후에도 번역 모델의 뼈대는 RNN이었습니다. 어텐션은 RNN 위에 얹는 보조 장치였습니다.

RNN의 문제는 구조 자체에 있습니다(1절). 열 번째 단어의 은닉 상태를 계산하려면 아홉 번째의 계산이 끝나 있어야 합니다. GPU가 아무리 많아도 한 문장 안에서는 순서대로 기다려야 하고, 문장이 길수록 이 제약이 커집니다.

합성곱으로 바꾼 모델은 병렬화는 됩니다. 하지만 한 층이 보는 범위가 좁아서, 멀리 떨어진 두 단어를 연결하려면 층을 여러 번 거쳐야 합니다. 거리가 멀수록 관계를 배우기 어렵습니다(2절).

저자들의 질문은 이것입니다. 어텐션이 그렇게 잘 작동한다면, RNN 없이 어텐션만으로 모델을 만들 수는 없을까.

## 핵심 아이디어

### 셀프 어텐션

Bahdanau Attention은 디코더가 인코더를 들여다보는 장치였습니다. 셀프 어텐션은 같은 문장 안에서 모든 단어가 다른 모든 단어를 직접 들여다보게 합니다. 두 단어가 아무리 멀어도 한 번의 연산으로 연결되고, 모든 위치를 동시에 계산할 수 있습니다.

계산 방식은 다음과 같습니다(3.2절). 각 단어의 벡터에서 세 가지 벡터를 만듭니다.

- **질의(query)**: "나는 이런 정보를 찾고 있다"
- **키(key)**: "나는 이런 정보를 갖고 있다"
- **값(value)**: 실제로 넘겨줄 내용

한 단어의 질의와 다른 모든 단어의 키를 내적해 점수를 구하고, 소프트맥스로 가중치를 만든 뒤 값들을 가중합합니다. 점수, 가중치, 가중합이라는 세 단계는 Bahdanau Attention과 같습니다. 달라진 것은 점수를 작은 신경망 대신 내적으로 구한다는 점입니다. 내적은 행렬 곱 한 번으로 모든 쌍을 계산할 수 있어 빠릅니다.

`Attention(Q, K, V) = softmax(Q·Kᵀ / √d_k)·V`

### 왜 √d_k로 나누는가

벡터의 차원이 크면 내적 값도 커지고, 큰 값이 소프트맥스에 들어가면 가중치가 한쪽으로 쏠려 기울기가 거의 사라집니다. 논문은 이를 막으려고 키 차원의 제곱근으로 나눕니다.

가상의 숫자로 보겠습니다. 키 차원이 64이고 세 단어에 대한 내적이 8, 4, 0.4라고 합시다.

| | 첫째 | 둘째 | 셋째 |
|---|---|---|---|
| 내적 그대로 소프트맥스 | 0.98 | 0.02 | 0.00 |
| 8로 나눈 뒤 소프트맥스 | 0.50 | 0.30 | 0.19 |

나누지 않으면 사실상 한 단어만 보게 되고, 나누면 여러 단어의 정보가 섞입니다.

```python
def attention(Q, K, V, mask=None):
    scores = Q @ K.transpose(-2, -1) / sqrt(d_k)    # 모든 쌍의 점수
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -inf) # 보면 안 되는 위치를 가린다
    weights = softmax(scores, dim=-1)
    return weights @ V
```

### 멀티 헤드

어텐션을 한 번만 하지 않고 8개를 나란히 돌린 뒤 결과를 이어 붙입니다. 기본 모델의 차원은 512이고 헤드 하나는 64차원을 씁니다. 헤드마다 서로 다른 종류의 관계를 볼 수 있게 하려는 것입니다. 한 번의 어텐션은 가중합이라 여러 관계가 평균으로 뭉개지는데, 헤드를 나누면 이를 피할 수 있습니다.

### 전체 구조

인코더와 디코더가 각각 같은 층 6개로 이뤄집니다(3.1절).

- **인코더 층**: 셀프 어텐션, 그다음 위치별 순방향 신경망
- **디코더 층**: 셀프 어텐션, 인코더 출력을 보는 어텐션, 순방향 신경망
- 모든 하위 층에 잔차 연결을 두고 층 정규화를 적용합니다.
- 순방향 신경망은 선형 변환 두 개 사이에 ReLU를 둔 구조이고, 안쪽 차원은 2,048입니다.

디코더의 셀프 어텐션에는 제약이 하나 있습니다. 번역문을 만들 때는 아직 만들지 않은 뒤쪽 단어를 볼 수 없어야 하므로, 자기보다 뒤에 있는 위치를 가립니다. 위 코드의 `mask`가 그 역할입니다.

### 학습할 때와 생성할 때의 차이

디코더는 앞에서 만든 단어들을 입력으로 받아 다음 단어를 예측합니다. 학습할 때는 정답 번역문 전체를 한꺼번에 넣고 마스크로 뒤쪽을 가립니다. 그러면 모든 위치의 예측을 한 번에 병렬로 계산할 수 있습니다. RNN과 달리 학습이 빠른 이유가 여기에 있습니다.

생성할 때는 사정이 다릅니다. 정답이 없으므로 단어를 하나 만들고, 그것을 입력에 붙여 다시 다음 단어를 만드는 과정을 반복해야 합니다. 병렬화의 이득은 학습과 인코더 쪽에 있고, 생성은 여전히 순차적입니다. 논문도 생성을 덜 순차적으로 만드는 것을 향후 과제로 꼽았습니다.

### 위치 정보

순환이 없으니 모델은 단어의 순서를 알 수 없습니다. 셀프 어텐션은 어떤 단어가 앞에 있고 어떤 단어가 뒤에 있는지를 구별하지 못합니다. 그래서 주파수가 서로 다른 사인과 코사인 함수로 만든 위치 값을 입력 임베딩에 더합니다(3.5절).

### 층 종류 비교

논문은 세 가지 층을 같은 기준으로 견줍니다(표 1, n은 문장 길이, d는 차원).

| 층 종류 | 층당 계산량 | 순차 연산 수 | 두 위치 사이 최대 경로 |
|---|---|---|---|
| 셀프 어텐션 | O(n²·d) | O(1) | O(1) |
| 순환 | O(n·d²) | O(n) | O(n) |
| 합성곱 | O(k·n·d²) | O(1) | O(log_k(n)) |

순차 연산 수가 O(1)이라는 것이 병렬화가 된다는 뜻이고, 최대 경로가 O(1)이라는 것이 먼 단어끼리도 바로 연결된다는 뜻입니다. 대가는 계산량이 길이의 제곱으로 늘어난다는 점입니다. 문장 길이가 차원보다 짧을 때는 셀프 어텐션이 순환 층보다 빠릅니다.

## 실험 결과

WMT 2014 번역 과제로 실험했습니다(5절).

| 항목 | 설정 |
|---|---|
| 영어-독일어 | 약 450만 문장 쌍, 공유 어휘 약 37,000개 |
| 영어-프랑스어 | 3,600만 문장, 어휘 32,000개 |
| 장비 | P100 GPU 8개 |
| 기본 모델 | 10만 스텝, 12시간, 파라미터 6,500만 개 |
| 대형 모델 | 30만 스텝, 3.5일, 파라미터 2억 1,300만 개 |
| 최적화 | Adam, 처음 4,000스텝 동안 학습률을 올린 뒤 서서히 낮춤 |
| 규제 | 드롭아웃 0.1, 레이블 스무딩 0.1 |

### 번역 품질

| 모델 | 영어-독일어 BLEU | 영어-프랑스어 BLEU |
|---|---|---|
| GNMT + RL 앙상블 | 26.30 | 41.16 |
| ConvS2S 앙상블 | 26.36 | 41.29 |
| Transformer (기본) | 27.3 | 38.1 |
| **Transformer (대형)** | **28.4** | **41.8** |

표 2의 수치입니다.

- 대형 모델은 단일 모델인데도 영어-독일어에서 기존 앙상블들을 2 BLEU 넘게 앞섭니다.
- 기본 모델도 영어-독일어에서는 기존 앙상블보다 높습니다. 12시간 학습한 결과입니다.
- 학습 비용도 작습니다. 영어-독일어 기준으로 대형 모델의 추정 연산량은 ConvS2S 앙상블의 3분의 1 이하입니다.

영어-프랑스어 대형 모델의 점수는 논문 본문 6.1절에 41.0으로 적혀 있지만, 초록과 표 2는 41.8입니다. 이 글은 표의 값을 따랐습니다.

번역 결과를 낼 때는 두 가지 요령을 더 썼습니다. 마지막 체크포인트 여러 개의 가중치를 평균했고(기본 모델 5개, 대형 모델 20개), 빔 크기 4의 빔 서치로 번역했습니다.

### 무엇이 중요한가

구성 요소를 하나씩 바꿔 본 실험입니다(표 3, 영어-독일어 개발 세트, 기본 모델은 25.8).

| 변경 | BLEU |
|---|---|
| 헤드를 1개로 | 24.9 |
| 헤드를 32개로 | 25.4 |
| 키 차원을 16으로 축소 | 25.1 |
| 드롭아웃 제거 | 24.6 |
| 사인 함수 대신 학습하는 위치 임베딩 | 25.7 |

- 헤드는 하나면 부족하고, 너무 많아도 떨어집니다.
- 키 차원을 줄이면 품질이 떨어집니다. 저자들은 단어 사이의 관련도를 판단하는 일이 쉽지 않으며, 내적보다 정교한 함수가 도움이 될 수 있다고 해석합니다.
- 드롭아웃을 빼면 1.2점이 떨어집니다. 과적합을 막는 데 큰 역할을 합니다.
- 위치 정보를 주는 방식은 결과에 거의 영향이 없습니다.

### 다른 과제

번역이 아닌 영어 구문 분석에도 적용했습니다. WSJ 데이터만으로 학습했을 때 F1 91.3, 준지도 학습에서는 92.7을 기록했습니다(표 4). 구조가 번역에만 통하는 것이 아님을 보인 결과입니다.

## 한계

논문의 결론은 한계를 따로 적지 않았습니다. 다만 본문에서 읽히는 것이 있습니다.

- **계산량이 길이의 제곱입니다.** 표 1이 보여 주는 대로입니다. 저자들도 아주 긴 입력에서는 주변 일부만 보는 제한된 어텐션을 검토하겠다고 적었습니다(4절).
- **실험은 번역과 구문 분석에 한정됩니다.** 이미지, 오디오, 영상 같은 다른 입력으로의 확장과 생성을 덜 순차적으로 만드는 일은 향후 과제로 남겼습니다(7절).

그 향후 과제가 이후 연구의 방향이 됐습니다. 커리큘럼의 다음 글들인 BERT는 인코더만, GPT-3는 디코더만 써서 규모를 키웠고, ViT는 같은 구조를 이미지 조각에 적용했습니다.

## 실무에서 가져갈 점

- **이후 모든 트랙의 공통 구조입니다.** 언어, 이미지, 음성, 시계열 트랙의 논문 대부분이 이 구조 위에서 무엇을 바꿨는지를 이야기합니다. 층 구성과 어텐션 계산은 외워 둘 가치가 있습니다.
- **길이의 제곱이 비용입니다.** 입력이 100토큰에서 1,000토큰으로 10배 늘면 어텐션이 계산할 쌍은 1만 개에서 100만 개로 100배 늘어납니다. 컨텍스트가 길어질수록 느려지고 비싸지는 이유입니다.
- **마스크를 확인하세요.** 직접 구현할 때 가장 흔한 버그는 디코더가 뒤쪽 단어를 볼 수 있게 열어 두는 것입니다. 학습 손실은 비정상적으로 빨리 떨어지는데 실제 생성은 엉망이 됩니다.
- **작은 부품이 성능을 좌우합니다.** 표 3에서 드롭아웃 하나만 빼도 성능이 눈에 띄게 떨어집니다. 학습률을 처음에 천천히 올리는 것도 같은 종류의 부품입니다. 구조를 고칠 때 이런 것들을 무심코 빼지 않도록 주의해야 합니다.
