## 한 줄 요약

WaveNet은 음성 파형을 이루는 샘플 하나하나를, 그 앞의 모든 샘플을 보고 확률 분포로 예측하는 생성 모델입니다. 합성곱의 간격을 층마다 두 배로 벌려 적은 층으로도 수천 샘플을 보게 했고, 출력은 256칸짜리 소프트맥스로 냈습니다. 텍스트 특징을 조건으로 주자 영어와 중국어 모두에서 당시 최고 음성 합성 시스템보다 자연스럽다는 평가를 받았습니다.

## 배경: 어떤 문제를 풀려는가

이 글은 커리큘럼 음성 트랙의 첫 번째 글입니다. 잔차 연결을 쓰므로 [ResNet](/2026/11/23/resnet-deep-residual-learning/) 글을, 미래를 가리고 다음 것을 예측하는 학습 방식이 같으므로 [Transformer](/2026/11/23/transformer-attention-is-all-you-need/) 글의 디코더 마스크 부분을 먼저 읽어 두면 좋습니다.

2016년의 음성 합성은 두 갈래였습니다(부록 A). 하나는 녹음해 둔 음성 조각을 이어 붙이는 연결 합성으로, 음질은 좋지만 녹음에 없는 말투를 만들기 어렵습니다. 다른 하나는 통계 모델이 5ms마다 스펙트럼, 기본 주파수(F0) 같은 보코더 파라미터를 예측하는 파라메트릭 합성으로, 유연하지만 소리가 뭉개집니다. 저자들은 둘 다 고정 길이 분석 창, 선형 필터, 가우시안 가정에 기댄다고 지적합니다.

WaveNet은 중간 단계를 모두 걷어 내고 파형을 직접 만듭니다. 문제는 길이입니다. 16kHz 음성은 1초에 샘플이 1만 6천 개이고, 한 음소만 해도 수백에서 수천 샘플에 걸칩니다. 5초짜리 문장도 8만 걸음짜리 시퀀스입니다. 저자들은 이미지를 픽셀 단위로 생성한 PixelCNN의 방식을 1차원 소리에 옮겨 이 문제를 풉니다.

## 핵심 아이디어

### 다음 샘플의 확률

파형 `x = (x_1, …, x_T)`의 확률을 조건부 확률의 곱으로 씁니다(식 1).

`p(x) = ∏_t p(x_t | x_1, …, x_{t-1})`

`x_t`는 지금 샘플, 조건부는 그 앞의 모든 샘플입니다. 학습은 정답 파형의 로그 가능도를 최대화하는 것이고, 생성은 분포에서 하나를 뽑아 입력 끝에 붙이는 일을 반복하는 것입니다. 가능도를 직접 계산할 수 있어 검증 세트로 과적합을 잴 수 있습니다(2절).

### 인과 합성곱과 팽창

미래 샘플을 보지 않게 하려고 합성곱의 출력을 몇 칸 밀어서, 시점 t의 출력이 t 이전 입력에만 의존하게 합니다(2.1절, 그림 2). 정답 파형 전체가 주어지므로 학습할 때는 모든 위치를 한 번에 계산하지만, 생성할 때는 한 샘플씩 차례로 만들어야 합니다.

평범한 인과 합성곱은 층을 하나 쌓을 때마다 보는 범위가 한 칸씩 늘어 너무 느리게 넓어집니다. 그래서 필터가 입력을 일정 간격으로 건너뛰며 보게 하는 팽창 합성곱을 씁니다(그림 3). 간격을 층마다 1, 2, 4, …, 512로 두 배씩 키운 묶음을 여러 번 반복합니다. 이 열 층짜리 묶음 하나가 보는 범위는 1,024샘플입니다. 필터 크기가 2일 때 범위는 `1 + (팽창 값의 합)`이고, 1부터 512까지의 합이 1,023이기 때문입니다.

가상의 설정으로 계산해 보겠습니다. 이 묶음을 세 번 쌓으면 범위는 `1 + 3 × 1,023 = 3,070`샘플이고, 16kHz에서 약 192ms입니다. 팽창 없이 같은 범위를 얻으려면 3,069층이 필요합니다. 논문은 실제 모델의 층 수를 밝히지 않았고, 실험별 수용 범위만 약 300ms(3.1절), 240ms(3.2절)라고 적었습니다.

### 256칸 소프트맥스와 μ-law

출력은 연속값 회귀가 아니라 범주 분포입니다(2.2절). 분포의 모양을 가정하지 않아도 되기 때문입니다. 다만 16비트 음성을 그대로 쓰면 칸이 65,536개라, 먼저 μ-law로 눌러 256칸으로 양자화합니다.

`f(x) = sign(x) · ln(1 + μ|x|) / ln(1 + μ)`, μ = 255, -1 < x < 1

로그 덕분에 작은 진폭에는 칸을 촘촘히, 큰 진폭에는 듬성듬성 배정합니다. 계산해 보면 f(0.01)은 약 0.23, f(0.5)는 약 0.88입니다. -1~1을 256칸으로 나눌 때 -0.01~0.01 구간은 선형 양자화로는 약 4칸이지만 μ-law로는 약 60칸을 차지합니다. 사람 귀가 민감한 작은 소리를 잘 보존하는 이유입니다. 논문은 이렇게 양자화한 음성이 원음과 아주 비슷하게 들린다고 적었습니다.

### 게이트 활성화, 잔차와 스킵 연결

각 층의 활성화는 ReLU 대신 두 갈래의 곱입니다(식 2).

`z = tanh(W_f * x) ⊙ σ(W_g * x)`

`W_f * x`는 무엇을 내보낼지(필터), `W_g * x`는 얼마나 통과시킬지(게이트)를 정하고, ⊙는 원소별 곱입니다. 가상의 숫자로 필터 출력이 1.0, 게이트 출력이 -2.0이면 `tanh(1.0) = 0.762`, `σ(-2.0) = 0.119`라 결과는 약 0.091입니다. 게이트가 신호의 약 88%를 막았습니다. 초기 실험에서 ReLU보다 나았다고 합니다(2.3절). 층마다 잔차 연결을 두고, 각 층의 출력을 스킵 연결로 모아 마지막 출력층에 넘깁니다(2.4절, 그림 4).

### 조건 걸기

같은 게이트에 조건 벡터 `h`를 더합니다(2.5절). 화자 번호처럼 시간에 따라 변하지 않는 전역 조건은 `V^T h`를 모든 시점에 똑같이 더합니다. 언어 특징처럼 시간에 따라 변하는 지역 조건은 전치 합성곱으로 샘플 속도까지 늘린 뒤 1×1 합성곱으로 더합니다. 값을 단순히 반복해 늘리는 방법은 조금 더 나빴다고 합니다.

### 의사 코드

```python
def wavenet(x, h):                      # x: (B, T) μ-law 정수, h: 조건
    a = causal_conv(one_hot(x, 256))
    skips = 0
    for d in [1, 2, 4, ..., 512] * 3:   # 팽창 묶음 반복
        f = causal_conv(a, dilation=d) + cond_f(h)
        g = causal_conv(a, dilation=d) + cond_g(h)
        z = tanh(f) * sigmoid(g)
        skips = skips + conv1x1_skip(z)
        a = a + conv1x1_res(z)          # 잔차 연결
    return conv1x1(relu(conv1x1(relu(skips))))  # 256칸 로짓

loss = cross_entropy(wavenet(x[:, :-1], h), x[:, 1:])  # 한 칸 밀어 맞힘
```

자주 틀리는 지점은 세 가지입니다. 패딩을 양쪽에 주면 미래가 새어 들어가, 학습 손실은 낮은데 생성은 잡음만 나옵니다. 인과 합성곱은 왼쪽에만 `(필터 크기 - 1) × 팽창`만큼 패딩해야 합니다. 입력과 정답을 한 칸 밀지 않는 실수도 같은 증상을 냅니다. 생성할 때 샘플마다 범위 전체(앞의 예라면 3,070샘플)를 다시 계산하지 말고, 층마다 지난 출력을 큐에 저장해 재사용해야 합니다.

### 음성 합성

비교 대상은 같은 데이터와 특징으로 학습한 HMM 기반 연결 합성과 LSTM 파라메트릭 합성입니다. WaveNet은 언어 특징만 받는 (L)과 F0도 받는 (L+F) 두 가지이고, F0와 음소 길이는 별도 모델이 예측합니다. 평가는 원어민 참가자가 학습에 쓰지 않은 100개 문장을 듣고 매겼고, 헤드폰 없이 참여한 약 40%는 제외했습니다(부록 B).

| 시스템 | 영어 MOS | 중국어 MOS |
|---|---|---|
| LSTM 파라메트릭 | 3.67 | 3.79 |
| HMM 연결 합성 | 3.86 | 3.47 |
| WaveNet (L+F) | 4.21 | 4.08 |
| 원음 (8비트 μ-law) | 4.46 | 4.25 |
| 원음 (16비트 PCM) | 4.55 | 4.21 |

표 1의 5점 척도 평균 의견 점수입니다. 가장 좋은 기존 시스템과 16비트 원음의 차이는 영어에서 0.69에서 0.34로, 중국어에서 0.42에서 0.13으로 줄었습니다. 각각 51%, 69% 감소입니다.

### 요소를 바꿨을 때

쌍대 비교(부록 B 표 2)에서 F0의 역할이 드러납니다.

| 비교 | 영어 선호(%) | 중국어 선호(%) |
|---|---|---|
| LSTM 대 WaveNet (L) | 18.7 대 69.3 | 25.0 대 23.3 |
| WaveNet (L) 대 WaveNet (L+F) | 17.8 대 37.9 | 10.0 대 25.5 |
| 연결 합성 대 WaveNet (L+F) | 20.1 대 49.3 | 7.6 대 55.9 |

중국어에서 F0 없는 WaveNet (L)은 LSTM과 통계적으로 차이가 없었습니다(p = 0.476). 성조가 의미를 가르는 언어라 음높이 정보를 직접 받지 못하면 이점이 사라진 것으로 보입니다. 이 해석은 글쓴이의 것입니다. 논문은 WaveNet (L)이 영어에서도 엉뚱한 단어에 강세를 주는 일이 있었고, F0의 장기 의존성을 240ms 범위로는 잡지 못한 탓일 수 있다고 봅니다(3.2절).

### 다른 과제

- **다화자 음성**: 화자만 주면 말처럼 들리지만 단어가 아닌 소리가 나옵니다. 범위가 약 300ms라 음소 두세 개만 기억하기 때문입니다. 화자를 늘리면 검증 성능이 올랐습니다(3.1절).
- **음악**: 수용 범위를 키우는 것이 중요했지만, 몇 초를 봐도 장르와 악기가 초 단위로 바뀌었습니다(3.3절).
- **음성 인식**: 팽창 합성곱 뒤에 160배 평균 풀링으로 10ms 프레임을 만들고, 다음 샘플 예측과 프레임 분류 두 손실로 학습해 TIMIT 음소 오류율 18.8을 냈습니다. 원시 파형으로 학습한 모델 중 최고라고 주장합니다(3.4절).

## 한계

논문이 밝힌 한계는 모두 수용 범위에서 나옵니다. 언어 특징만으로는 운율이 어색했고, 다화자 음성과 음악은 긴 일관성이 없었습니다. 운율 문제는 외부 F0 모델에 맡겨 우회했습니다.

논문이 적지 않은 더 큰 한계는 생성 속도입니다. 논문에는 속도 수치가 없지만, 샘플을 하나씩 만들어야 하므로 1초에 1만 6천 번 신경망을 돌려야 합니다. DeepMind의 WaveNet 소개 페이지는 초기 버전이 1초 분량에 몇 시간이 걸렸다고 회고합니다.

후속 연구는 이 문제를 정면으로 다뤘습니다. Parallel WaveNet(2017)은 학습된 WaveNet을 교사로 두고, 한 번에 모든 샘플을 내는 역자기회귀 흐름 학생 모델을 확률 밀도 증류로 학습해 실시간보다 20배 넘게 빠르게 만들었습니다. 2017년 10월 DeepMind는 이렇게 개선한 WaveNet이 원본보다 1,000배 빠르고, 1초 음성을 50ms에 24kHz 16비트로 만든다고 발표했습니다. 입력 쪽도 바뀌었습니다. 이 트랙의 다음 글인 Tacotron 2는 손으로 만든 언어 특징 대신 텍스트에서 예측한 멜 스펙트로그램으로 WaveNet을 조건화합니다. 이어지는 HiFi-GAN은 자기회귀를 버리고 GAN으로 보코더를 빠르게 만듭니다.

## 실무에서 가져갈 점

- **신경망 보코더의 출발점입니다.** 소개 페이지에 따르면 WaveNet과 후속 모델 WaveRNN은 Google Assistant, 지도 길 안내, 음성 검색, Cloud Text-to-Speech에 쓰였습니다. 이후 "음향 특징 예측 모델 + 신경망 보코더" 구조에서 WaveNet은 보코더 자리를 맡습니다(Tacotron 2).
- **팽창 인과 합성곱은 긴 1차원 신호에 두루 쓸 수 있습니다.** 범위를 층 수의 로그 비용으로 넓힙니다. 범위는 `1 + (필터 크기 - 1) × (팽창 값의 합)`으로 직접 계산해 확인하세요.
- **연속값도 분류로 풀 수 있습니다.** μ-law 256칸 소프트맥스는 회귀보다 분포 표현이 자유롭습니다. 이후 오디오를 이산 토큰으로 다루는 흐름(이 트랙의 SoundStream, AudioLM)의 먼 조상입니다.
- **학습 속도와 생성 속도를 따로 보세요.** 자기회귀 모델은 학습은 병렬, 생성은 순차입니다. LLM 토큰 생성이 느린 것과 같은 이유이고, 캐싱이 첫 번째 최적화입니다.
