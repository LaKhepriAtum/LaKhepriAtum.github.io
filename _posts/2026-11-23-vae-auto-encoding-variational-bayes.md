## 한 줄 요약

잠재 변수가 있는 생성 모델은 사후 분포를 계산할 수 없어서 학습이 어려웠습니다. 이 논문은 샘플링을 "노이즈를 입력으로 받는 함수"로 바꿔 써서, 인코더와 디코더를 평범한 경사 하강법으로 한꺼번에 학습할 수 있게 했습니다. 그렇게 만든 모델이 VAE입니다.

## 배경: 어떤 문제를 풀려는가

이 글은 커리큘럼 공통 기초 트랙의 첫 번째 글이며, 먼저 읽어 둘 글은 없습니다.

손글씨 숫자 이미지를 생각해 봅시다. 픽셀은 수백 개지만, 이미지를 결정하는 요인은 "어떤 숫자인가, 얼마나 기울었나, 획이 얼마나 굵은가" 정도로 훨씬 적습니다. 이렇게 보이지 않는 소수의 요인 z가 먼저 정해지고, 거기서 데이터 x가 만들어진다고 가정하는 모델이 잠재 변수 모델입니다.

이 모델을 학습하려면 거꾸로 가는 계산이 필요합니다. 이미지 x를 보고 "이것을 만든 z는 무엇이었을까"를 알아야 하는데, 이것이 사후 분포입니다. 문제는 디코더에 비선형 은닉층이 하나만 있어도 이 분포를 계산할 수 없게 된다는 점입니다(2.1절).

당시의 대안은 각각 막히는 지점이 있었습니다.

- EM 알고리즘은 사후 분포를 계산할 수 있어야 쓸 수 있습니다.
- 평균장 변분 추론은 기댓값을 수식으로 풀어야 하는데, 이것도 일반적으로는 불가능합니다.
- 샘플링 기반 방법은 데이터 하나마다 반복 샘플링을 돌려야 해서 큰 데이터에는 너무 느립니다.
- 근사 분포의 파라미터에 대해 기울기를 단순하게 추정하면 분산이 너무 커서 쓸 수 없습니다(2.2절).

저자들이 원한 것은 큰 데이터에서 미니배치로 돌아가고, 데이터마다 반복 계산을 하지 않는 방법이었습니다.

## 핵심 아이디어

### 인코더를 함께 학습한다

사후 분포를 정확히 구하는 것은 포기하고, x를 받아 z의 분포를 근사해서 내놓는 신경망을 따로 둡니다. 논문은 이것을 인식 모델이라 부르고, 지금은 인코더라고 합니다. 반대 방향인 생성 모델은 디코더입니다.

논문의 예시에서 인코더는 가우시안의 평균 μ와 표준편차 σ를 출력합니다(3절). 즉 "이 이미지의 z는 대략 μ 근처이고, σ만큼 불확실하다"고 답하는 셈입니다.

### 샘플링을 바꿔 쓴다

여기서 문제가 생깁니다. 디코더에 넣을 z는 인코더가 내놓은 분포에서 뽑아야 하는데, "분포에서 뽑는다"는 연산은 미분할 수 없습니다. 기울기가 그 지점에서 끊겨 인코더까지 전달되지 않습니다.

해법은 한 줄입니다. z를 직접 뽑지 않고, 표준 정규분포에서 노이즈 ε을 뽑은 뒤 계산으로 z를 만듭니다.

`z = μ + σ·ε`

가상의 숫자로 따라가 보겠습니다. 인코더가 μ = 0.5, σ = 0.2를 냈고 뽑힌 노이즈가 ε = 1.3이면 z = 0.5 + 0.2 × 1.3 = 0.76입니다. 결과는 같은 분포에서 뽑은 것과 똑같습니다. 그런데 이제 z는 μ와 σ에 대한 단순한 덧셈과 곱셈이므로 미분이 됩니다. 무작위성은 ε이라는 입력으로 빠져나갔고, 학습할 파라미터와는 분리됐습니다. 이것이 재매개변수화 기법입니다(2.4절).

논문은 가우시안 외에도 이 방식을 쓸 수 있는 경우를 세 가지로 정리합니다. 역누적분포함수를 계산할 수 있는 분포, 가우시안처럼 위치와 척도로 표현되는 분포, 다른 변수의 변환으로 만들 수 있는 분포입니다.

### 목적 함수는 두 항이다

우리가 정말 키우고 싶은 것은 데이터의 로그 가능도 log p(x)입니다. 이것은 계산할 수 없으므로, 그보다 항상 작거나 같으면서 계산할 수 있는 값인 하한을 대신 키웁니다.

`log p(x) ≥ E[log p(x|z)] − KL(q(z|x) ‖ p(z))`

오른쪽이 하한이고, 두 항으로 나뉩니다(3절).

- **복원 항**: 인코더가 낸 z를 디코더에 넣었을 때 원래 x가 얼마나 잘 복원되는지를 봅니다. 오토인코더의 복원 오차에 해당합니다.
- **KL 항**: 인코더가 낸 분포가 사전 분포 N(0, I)에서 얼마나 떨어져 있는지에 대한 벌점입니다.

두 항은 서로 반대 방향으로 당깁니다. 복원만 잘하려면 인코더는 이미지마다 σ를 0에 가깝게 줄이고 μ를 서로 멀리 떨어뜨리는 것이 유리합니다. 그러면 잠재 공간에 빈 구멍이 생겨, 나중에 사전 분포에서 z를 뽑아 새 이미지를 만들 때 엉뚱한 결과가 나옵니다. KL 항이 이것을 막습니다.

가우시안끼리의 KL은 수식으로 바로 계산되어 샘플링이 필요 없습니다. 잠재 변수 한 차원당 `0.5 × (μ² + σ² − log σ² − 1)`입니다. 앞의 예시(μ = 0.5, σ = 0.2)를 넣으면 약 1.25이고, 인코더가 사전 분포와 똑같이 μ = 0, σ = 1을 내면 0이 됩니다.

논문은 추정 방식을 두 가지로 제시합니다. 두 항을 모두 샘플링으로 추정하는 일반형과, KL 항은 수식으로 계산하고 복원 항만 샘플링하는 방식입니다. 뒤쪽이 보통 분산이 더 작다고 설명하며, VAE는 뒤쪽을 씁니다(2.3절).

### 일반 오토인코더와 무엇이 다른가

구조만 보면 입력을 압축했다가 복원하는 오토인코더와 같습니다. 차이는 두 가지입니다.

- 일반 오토인코더는 입력마다 점 하나를 내놓습니다. VAE는 분포를 내놓고 거기서 뽑은 값을 디코더에 넣습니다. 그래서 비슷한 z에서는 비슷한 출력이 나오도록 잠재 공간이 매끄럽게 정리됩니다.
- 잡음 제거 오토인코더나 희소 오토인코더 같은 규제형 오토인코더는 규제의 세기를 사람이 정해야 합니다. VAE의 KL 항은 하한에서 저절로 나오는 것이라 따로 정할 필요가 없다는 점을 논문은 장점으로 듭니다(4절).

학습이 끝난 뒤 새 데이터를 만드는 방법도 여기서 나옵니다. 인코더는 버리고, 사전 분포 N(0, I)에서 z를 뽑아 디코더에 넣으면 됩니다. KL 항이 인코더의 출력을 사전 분포 근처로 붙잡아 두었기 때문에 가능한 일입니다. 논문 부록에는 잠재 변수를 2차원으로 두고 학습한 결과를 시각화한 그림이 실려 있습니다.

### 미니배치로 학습한다

데이터 전체가 N개일 때 미니배치 M개로 추정한 값에 N/M을 곱해 전체 하한을 추정합니다. 미니배치가 100개 정도로 충분히 크면 데이터 하나당 ε은 1개만 뽑아도 된다고 논문은 말합니다(2.3절).

학습 한 스텝을 의사 코드로 쓰면 다음과 같습니다.

```python
mu, log_var = encoder(x)                 # 분포의 평균과 로그 분산
eps = randn_like(mu)                     # 노이즈를 바깥에서 뽑는다
z = mu + exp(0.5 * log_var) * eps        # 재매개변수화
x_hat = decoder(z)

recon = reconstruction_loss(x_hat, x)    # 복원 항
kl = 0.5 * sum(mu**2 + exp(log_var) - log_var - 1)
loss = recon + kl
loss.backward()                          # 인코더까지 기울기가 흐른다
```

표준편차 대신 로그 분산을 출력하게 하는 것은 구현상의 관례입니다. 신경망 출력에 양수 제약을 걸지 않아도 되기 때문입니다.

처음 구현할 때 헷갈리기 쉬운 점이 두 가지 있습니다.

- **ε은 학습되는 값이 아닙니다.** 스텝마다, 데이터마다 새로 뽑는 입력입니다. 같은 이미지라도 매번 조금씩 다른 z가 디코더에 들어가고, 디코더는 그 흔들림을 견디도록 학습됩니다.
- **두 항의 단위를 맞춰야 합니다.** 복원 항은 픽셀 전체에 대한 합인데 KL 항만 평균으로 계산하면, 의도하지 않게 KL 항의 비중이 크게 달라집니다. 둘 다 데이터 하나당 합으로 구한 뒤 배치에 대해 평균하는 것이 논문의 식과 맞습니다.

학습이 끝나면 추론은 인코더를 한 번 통과시키는 것으로 끝납니다. 데이터마다 반복 계산을 돌릴 필요가 없습니다.

## 실험 결과

MNIST와 Frey Face 두 이미지 데이터로 실험했습니다(5절).

| 항목 | 설정 |
|---|---|
| 은닉 유닛 | MNIST 500개, Frey Face 200개 |
| 미니배치 크기 | 100 |
| 데이터당 노이즈 샘플 | 1개 |
| 최적화 | Adagrad, 스텝 크기는 0.01, 0.02, 0.1 중에서 선택 |
| 초기화 | N(0, 0.01)에서 무작위로 뽑음 |

Frey Face는 데이터가 훨씬 작아서 과적합을 줄이려고 은닉 유닛을 줄였습니다.

- **wake-sleep과 비교.** 같은 인코더 구조를 쓰는 wake-sleep 알고리즘과 견주었을 때, 모든 실험에서 더 빨리 수렴하고 더 좋은 해에 도달했습니다(그림 2).
- **잠재 변수를 늘려도 과적합이 늘지 않았습니다.** 잠재 차원을 여러 값으로 바꿔 가며 실험했는데, 차원을 키워도 과적합이 심해지지 않았습니다. 저자들은 목적 함수인 하한 자체가 규제 역할을 하기 때문이라고 설명합니다(그림 2).
- **샘플링 기반 방법과 비교.** 은닉 유닛 100개, 잠재 변수 3개인 작은 모델로 몬테카를로 EM과도 비교했습니다. 이 방법은 온라인 학습이 아니어서 MNIST 전체에는 효율적으로 적용할 수 없었습니다(그림 3).
- **속도.** CPU에서 학습 샘플 100만 개당 20~40분이 걸렸다고 보고합니다.

논문 본문은 이 결과들을 학습 곡선 그림으로 제시합니다. 그래서 이 글에도 성능 수치는 옮기지 않았습니다.

## 한계

논문에서 확인되는 한계는 다음과 같습니다.

- **연속 잠재 변수를 전제로 합니다.** 재매개변수화는 z가 연속값일 때 성립합니다. 비교 대상인 wake-sleep은 이산 잠재 변수도 다룰 수 있다고 논문이 직접 밝힙니다(4절).
- **실험 규모가 작습니다.** 작은 MLP와 작은 이미지 데이터에 머뭅니다. 합성곱 신경망을 쓴 깊은 계층 모델, 시계열 모델, 잠재 변수가 있는 지도 학습은 향후 과제로 남겼습니다(7절).

이후 연구에서는 다른 문제도 드러났습니다. 디코더가 강력하면 z를 보지 않고도 복원을 잘하게 되어 잠재 변수가 무시되는데, 이것을 사후 붕괴(posterior collapse)라고 합니다. 2017년의 VQ-VAE는 잠재 변수를 이산 코드로 바꿔 이 문제를 피했습니다.

## 실무에서 가져갈 점

- **재매개변수화는 범용 도구입니다.** 계산 중간에 샘플링이 끼어 있어 미분이 끊길 때, 무작위성을 입력 쪽으로 빼내는 이 방법을 그대로 쓸 수 있습니다. 구현할 때는 노이즈를 모델 바깥에서 뽑아 넣는다는 점만 지키면 됩니다.
- **지금 가장 흔한 쓰임은 압축기입니다.** 잠재 확산 모델은 이미지를 VAE로 작은 잠재 공간에 압축한 뒤 그 위에서 확산 모델을 학습합니다. 이때 KL 항은 잠재 공간의 크기와 분포를 다듬는 역할을 합니다. 커리큘럼의 Latent Diffusion 글에서 다시 다룹니다.
- **두 항의 균형이 조절 손잡이입니다.** KL 항을 강하게 걸면 잠재 공간은 고르게 정리되지만 복원 품질이 떨어지고, 약하게 걸면 그 반대가 됩니다. 복원이 흐릿하거나 생성 결과가 이상할 때 가장 먼저 볼 곳입니다.
- **학습 중에는 두 항을 따로 기록하세요.** 합친 손실만 보면 KL 항이 0으로 주저앉는 사후 붕괴를 알아채기 어렵습니다.
